# Final-Project
## Dataset
Due to GitHub's file size limits, the raw USAspending dataset (2.18M rows) is not included in this repository. 

**To replicate this project:**
1. Download the raw data directly from https://drive.google.com/drive/folders/1cPq6wquuaQVp7gv3haijJhJN6QhAWuZ5?usp=sharing.
2. Upload the CSV files to your Google Drive.
3. Update the `file_path` variables in the Jupyter Notebooks to match your local or Google Drive directory structure.
